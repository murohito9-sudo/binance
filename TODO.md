# TODO Nalar AI

- [x] **Percakapan AI berbahasa Indonesia** — Jadikan aplikasi sebagai asisten AI percakapan umum yang lebih layak digunakan. Antarmuka percakapan berbahasa Indonesia dengan kolom prompt, status proses, respons asisten, serta dukungan format konten seperti Markdown dan blok kode. Hubungkan percakapan ke model bahasa, pertahankan konteks percakapan, dan jelaskan kegagalan secara dapat dipulihkan.
- [x] **Riwayat, pencarian, dan kontrol percakapan** — Pembuatan percakapan baru serta riwayat chat yang dapat dibuka kembali, diberi judul, diubah namanya, dan dihapus. Pencarian percakapan berdasarkan judul atau isi untuk menemukan chat terdahulu dengan cepat. Kontrol respons asisten untuk menyalin, menghentikan proses, membuat ulang jawaban, dan memberikan umpan balik.
- [x] **Mode AI dan lampiran** — Pilihan model atau mode AI sebelum dan selama percakapan, dengan penjelasan singkat mengenai kegunaan tiap opsi. Unggah berkas melalui pemilih berkas atau drag-and-drop, lengkap dengan pratinjau lampiran, validasi, dan pelepasan berkas sebelum dikirim. Lampiran digunakan sebagai konteks bila formatnya didukung layanan.
- [x] **Responsif dan aksesibel** — Tata letak responsif untuk desktop, tablet, dan ponsel dengan sidebar riwayat yang adaptif serta navigasi yang efisien. Aksesibilitas menyeluruh melalui navigasi keyboard, fokus yang terlihat, label pembaca layar, kontras memadai, dan dukungan preferensi pengurangan gerak.
- [x] **Penyederhanaan aplikasi sumber** — Sempurnakan aplikasi yang dilampirkan menjadi pengalaman asisten AI umum. Pertahankan hanya komponen, konten, dan pola interaksi aplikasi asal yang mendukung pengalaman asisten AI; hilangkan bagian dashboard kripto yang tidak relevan.
- [ ] **Login khusus pemilik** — Sediakan login nyata melalui Manus OAuth; validasi nonce/state, token HS256, `appId`, kedaluwarsa sesi, dan identitas pemilik yang diizinkan. Batasi semua endpoint percakapan, lampiran, feedback, dan Binance ke pemilik saja. Untuk Preview HTTPS gunakan cookie `webdev_app_session` dengan `SameSite=None; Secure`; jangan memakai login palsu atau melewati login di mode pengembangan. Implementasi telah dibuat; callback OAuth penuh belum diuji dengan login interaktif.
- [ ] **Sinkronisasi Binance Spot baca-saja** — Ambil data akun hanya setelah pemilik meminta sinkronisasi. API key dan private key Ed25519 berada di secret store dan hanya di server. Permintaan privat hanya `GET /api/v3/account` bertipe `USER_DATA`; data harga publik hanya memakai endpoint `GET` Binance Spot. Jangan kirim kredensial ke browser, database, chat AI, storage, atau log; jangan simpan saldo/posisi Binance di database atau riwayat percakapan. Pastikan petunjuk koneksi meminta izin baca data saja dan melarang izin trade, withdraw, margin, maupun futures. Implementasi tersedia; secret Binance belum dikonfigurasi dan sinkron akun live belum diuji.
- [x] **Wizard koneksi Binance yang mudah diikuti** — Saat pemilik menekan “Hubungkan Binance Spot”, tampilkan langkah bernomor yang menjelaskan cara membuat API key Ed25519 dengan izin baca saja di Binance, menyebut persis `BINANCE_API_KEY` dan `BINANCE_ED25519_PRIVATE_KEY`, serta menunjukkan bahwa nilainya harus ditambahkan lewat Secrets proyek—bukan dimasukkan ke chat atau form halaman. Untuk mencoba Preview, minta pengguna memilih lingkungan Development; nilai Development tidak otomatis berlaku di Production. Jika status belum berubah setelah menyimpan secrets, minta pengguna restart Preview lalu memeriksa kembali. Sediakan tombol untuk memeriksa apakah secrets sudah tersedia dan tampilkan nama yang masih kurang tanpa pernah menampilkan nilainya. Jika belum lengkap atau format private key tidak valid, jelaskan langkah berikutnya dan jangan aktifkan sinkronisasi. Setelah konfigurasi valid, sediakan tombol eksplisit “Tes koneksi & sinkronkan saldo”; jika Binance menerima akses, tandai status “Terhubung · baca-saja” pada sesi tab dan tampilkan waktu serta sumber saldo. Jika gagal, jelaskan tindakan aman untuk memperbaiki permission, IP allowlist, atau format key tanpa membocorkan credential. Jangan mengaku terhubung sebelum respons akun sukses. Implementasi selesai; endpoint anonim menolak akses dan tiga uji status secret lulus. Uji akun live menunggu secrets pemilik.
- [ ] **Saran stop-loss transparan untuk Spot** — Batasi analisis V1 pada posisi Spot long dan pasangan langsung USDT. Tampilkan daftar saldo free/locked dan waktu/sumber data. Untuk usulan angka, minta harga masuk rata-rata dan batas kerugian pemilik; gunakan ATR(14) pada timeframe 1h, 4h, atau 1d dan berikan skenario 1.5x, 2x, dan 3x ATR dengan estimasi kerugian terhadap saldo yang terbaca. Tandai data sebagai single-source Binance, tunjukkan asumsi/waktu candle, tahan rekomendasi angka jika input atau data penting kurang/stale, dan jangan menjanjikan hasil. Kalkulasi murni lulus empat kelompok unit test; alur data live menunggu secret Binance.
- [x] **Batas tanpa transaksi** — Nalar hanya menghasilkan analisis dan level usulan yang belum dikirim. Tidak ada endpoint transaksi atau tindakan untuk membuat, mengubah, membatalkan, menandatangani, atau mengirim order, memindahkan aset, memakai wallet, atau mengakses Futures/Margin. Tidak ada monitoring otomatis atau eksekusi latar belakang; jika pemilik memilih trading, keputusan dan transaksi dilakukan sendiri di luar Nalar. Audit kode mengonfirmasi modul Binance hanya memanggil endpoint GET Spot.
- [x] **Logo Nalar dari gambar pemilik** — Gunakan gambar yang pemilik lampirkan sebagai logo Nalar; pertahankan wordmark dan mark biru-peraknya, tampilkan pada layar masuk dan identitas aplikasi desktop/mobile, serta gunakan mark sebagai ikon situs. Lockup dipakai pada layar masuk; mark pada navigasi desktop/mobile dan favicon; metadata proyek memakai ikon HTTPS. Tiga aset storage merespons sebagai PNG di Preview.
- [x] **Indikator teknikal dan sizing risiko Binance Spot baca-saja** — Tampilkan EMA(20/50), RSI(14), MACD(12,26,9), Bollinger Bands(20,2) dan bias indikator berdasarkan candle Binance Spot selesai pada timeframe pilihan (1h, 4h, atau 1d); cantumkan waktu candle, harga dan sumber. Tambahkan ukuran posisi maksimum teoritis berbasis anggaran risiko dan level stop ATR(14), tampilkan estimasi rugi saldo kini, dan jelaskan biaya, spread, slippage, gap harga, aturan minimum/step serta keterbatasan single-source yang belum tercakup. Analisis hanya memberi konteks, bukan perintah transaksi; tidak membuat, mengubah, atau membatalkan order. Delapan uji unit lolos; integrasi akun live tetap menunggu secrets Binance.

- [ ] **Tautan Nalar dapat diakses** — Terbitkan checkpoint terbaru sebagai situs HTTPS dengan container backend agar URL dapat dibuka lewat browser. Server harus menjalankan skrip produksi dari lockfile, melayani `public/`, menghormati `PORT` (default 3000), menyediakan `GET /api/health` tanpa login untuk readiness, serta membaca secrets hanya saat runtime. Pertahankan login OAuth khusus pemilik untuk seluruh data privat. Jangan mengaktifkan auto-publish; minta konfirmasi platform bila perubahan visibilitas memperluas akses. Sampaikan URL hanya setelah hasil publish berhasil dikonfirmasi.
